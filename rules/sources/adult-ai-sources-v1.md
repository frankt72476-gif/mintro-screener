# Adult AI public-rule excerpts v1

Clause corpus for rules/ruleset-adult-ai.json (D-286). There is no published IQwallet standard for
this vertical. Each line under the heading below is a sentence of a public rule or statute, quoted
byte for byte from the primary source named here, and it is what the report prints under Source.
It is not a standard, and nothing here says a merchant does or does not comply with it.

The packages/ruleset validator asserts that each clause on a source: programme rule is a byte-exact
substring of this file and a whole line under the heading. Quotes and dashes are the sources' own
characters and must not be normalised. Emphasis is stripped. Line breaks inside a sentence in the
source are joined with single spaces; nothing else is changed.
